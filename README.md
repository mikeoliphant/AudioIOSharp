# AudioIOSharp

Real-time, allocation-free audio I/O for .NET, on Windows and Linux.

Shared by [AudioPlugSharp](https://github.com/mikeoliphant/AudioPlugSharp) (its standalone host) and SpiceForge.

The code in **AudioIOSharp/** started as SpiceForge's audio implementation (SpiceForgeServer/Audio, as of SpiceForge commit ec85495) and is being refactored into a library of its own.
